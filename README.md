# ResearchHub AI

AI-powered PDF analysis system using Streamlit and Groq AI.

## Features

- Upload PDF documents
- Extract text from PDFs
- Generate AI-powered summaries
- Ask questions about uploaded PDFs
- Get intelligent answers using Groq LLM

## Technologies Used

- Python
- Streamlit
- Groq AI
- PyPDF
- FastAPI

## Live Demo

https://researchapp-ai.streamlit.app

## GitHub Repository

https://github.com/Vinnu13-01-05/ResearchHub-AI

## How It Works

1. Upload a PDF document
2. The application extracts text from the PDF
3. Groq AI processes the document
4. Users can generate summaries
5. Users can ask questions about the document
6. AI provides answers based on the uploaded PDF
